# Tiro 비즈니스 일본어 표현집 생성

Tiro 미팅 노트를 읽어 회의에서 오간 일본어 표현을 **정중한 비즈니스 일본어(敬語)로 정정·개선**하고,
각 문장 아래에 한국어 번역을 붙여 **엑셀 파일**로 내보낸다.

## 진행 순서

### 1. 미팅 노트 조회
- `mcp__tiro__search`로 사용자가 말한 미팅 제목/키워드를 검색해 `noteGuid`를 찾는다.
- `mcp__tiro__get_note`를 `include: ["summary", "transcript", "documents"]`로 호출해 전문(transcript)과 요약을 확보한다.
- 어떤 미팅인지 모호하면 검색 결과를 제시하고 사용자에게 확인한다.

### 2. 문장 추출·정정
- transcript의 **구어체·반말·불완전한 표현**을 비즈니스 정중체(です・ます체, 겸양/존경어)로 다듬는다.
- 더 자연스럽거나 정확한 표현이 있으면 개선한다(원문 직역 금지, 실제 비즈니스 현장에서 쓰는 표현으로).
- 미팅의 흐름에 따라 **카테고리(분류)** 로 묶는다. (예: 인사 → 운영 매뉴얼 → 장애 대응 → 집계 정의 → 마무리 등)
- 기본 분량은 **50~100문장** (사용자가 별도 지정 시 그에 맞춘다).
- 각 문장은 `(카테고리, 일본어, 한국어번역)` 형태로 정리한다.

### 3. 엑셀 생성
- `scripts/build_phrasebook.py`를 참고/사용한다. 핵심 레이아웃 규칙:
  - 열: `No.` | `カテゴリ (분류)` | `文章 (日本語 / 한국어)`
  - **한국어 번역은 일본어 셀 바로 아래 행**에 같은 열로 배치한다(좌우 분리 X).
  - `No.`/`카테고리` 셀은 일본어·한국어 두 행에 걸쳐 병합한다.
  - 일본어 행은 굵은 남색(흰 배경), 한국어 행은 초록 이탤릭(연한 파란 배경)으로 구분.
  - 헤더 고정(freeze panes), 자동 줄바꿈(wrap_text), 테두리 적용.
- `openpyxl`이 없으면 `pip install openpyxl`로 설치한다.
- 출력 파일명: `cosme_business_japanese.xlsx` (또는 미팅에 맞는 이름).

### 4. 전달 및 커밋
- `SendUserFile`로 생성한 xlsx를 사용자에게 전달한다.
- 저장소 작업 중이면 지정된 작업 브랜치에 커밋·푸시한다(요청 없으면 PR 생성 금지).

## 스크립트 사용법

문장 데이터를 `ROWS` 리스트(`(카테고리, 일본어, 한국어)` 튜플)로 채운 뒤 실행하면 동일 포맷의 엑셀이 만들어진다.
`scripts/build_phrasebook.py`의 `ROWS`를 교체하거나, 같은 헬퍼 함수를 호출해 생성한다.

```bash
python3 .claude/skills/tiro-jp-phrasebook/scripts/build_phrasebook.py
```

## 참고 사항
- 추가 주제(예: `中継事故 / 중계 사고` 같은 특정 키워드)를 사용자가 지정하면 해당 카테고리를 신설해 문장을 보강한다.
- Tiro MCP 권한은 읽기 전용(`mcp:notes:read`)이므로 노트 수정은 하지 않는다.
